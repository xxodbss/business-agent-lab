# 브랜드 틴 (v1 프로토타입)

동네 가게를 찍으면 한지 조각이 되어 알루미늄 틴케이스에 담기는 모바일 웹앱.

## 실행

```bash
cd brand-tin
python3 -m http.server 8080
```

### 지도

키나 가입 없이 동작하는 OpenStreetMap 공용 서버를 쓴다 (과제·프로토타입용).

- 지도 그림: OpenStreetMap 공용 타일 + Leaflet. CSS 필터로 빛바랜 종이 톤을 입혔다.
- 좌표 → 동네: Nominatim. 한국에서는 `suburb` 값이 행정동이다 (연남동, 망원1동 등). 초당 1회 제한을 코드에서 지킨다.
- 두 서버 모두 가벼운 사용만 허용한다. 실서비스로 키우면 `js/config.js`, `js/geo.js`, `js/map.js` 만 카카오나 네이버로 바꾸면 된다.

브라우저에서 http://localhost:8080 를 연다. 빌드 과정은 없다. ES 모듈을 쓰기 때문에 파일을 더블클릭해서 열면 동작하지 않는다.

- 데스크톱: 조각은 마우스로 끌고, 방향키로 틴을 기울인다.
- 폰: 기울기 센서는 HTTPS에서만 동작한다. 같은 Wi-Fi에서 `http://<내 IP>:8080` 로 접속하면 촬영과 드래그는 되지만 기울기는 동작하지 않는다.

## 구조

| 파일 | 역할 |
|---|---|
| `js/main.js` | 앱 흐름: 지도 → 틴, 뚜껑, 기울기, 조각 추가와 저장 |
| `js/map.js` | 첫 화면 지도 (동네 틴 마커, 확대 시 조각 핀), 위치 고르기 |
| `js/geo.js` | 사진 GPS, 현재 위치, 좌표 → 행정동 |
| `js/config.js` | 지도 타일, 주소 검색 서버 주소 |
| `js/tin.js` | 틴 바닥 그리기, Matter.js 물리, 떨어지는 애니메이션, 터치 |
| `js/hanji.js` | 사진을 섬유 테두리의 한지 인쇄물로 렌더링 (시드 기반이라 모양이 재현됨) |
| `js/crop.js` | 3:4 크롭 (드래그, 핀치) |
| `js/ui.js` | 한지 확인 화면, 스펙시트 카드 |
| `js/palette.js` | k-means 대표 컬러 추출 |
| `js/store.js` | IndexedDB 저장 (사진 Blob, 메타, 조각 위치) |
| `js/demo.js` | 테스트용 가짜 간판 |
